## Checkpoint locations

The release contains **32 `.pt` files** for the ReSID-backbone experiments: one supervised base and fifteen final RL models per dataset. Each shipped RL checkpoint is the actual600-step model used for the five-seed comparison.

| Experiment | Shipped starting weights | Shipped final RL weights | Newly trained checkpoints |
|---|---|---|---|
| Industrial | `resid_sgpo_release/industrial/checkpoints/base/gr.pt` | `resid_sgpo_release/industrial/checkpoints/seed{42..46}/{grpo,gspo,sgpo}.pt` | the directory passed to `train.py --output` |
| Office | `resid_sgpo_release/office/checkpoints/base/gr.pt` | `resid_sgpo_release/office/checkpoints/seed{42..46}/{grpo,gspo,sgpo}.pt` | the directory passed to `train.py --output` |
| Rec-R1-style | base model path set by `QGEN_PRETRAIN` | trained model directories selected in the evaluation command | `qgen_sgpo_release/checkpoints/<exp_name>/checkpoint-599/` |

For either ReSID dataset, the command `python train.py --method sgpo --seed 42 --output runs/sgpo-seed42` saves `sgpo-step100.pt` through `sgpo-step600.pt`, `sgpo-best.pt`, validation metrics and training logs under that output directory. The experiment comparison uses `sgpo-step600.pt`. Run commands from the selected dataset directory.
