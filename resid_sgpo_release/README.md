# ReSID-backbone experiments

Industrial and Office are independent sibling dataset releases. Both use parallel6×16 SIDs, the shared Transformer encoder–decoder architecture, five RL seeds42–46, and actual600-step GRPO/GSPO/SGPO checkpoints.

```text
resid_sgpo_release/
├── README.md
├── LICENSE
├── industrial/
│   ├── README.md
│   ├── train.py                     # one method and one RL seed
│   ├── run_all.py                   # all15method/seed combinations
│   ├── evaluate.py                  # checkpoint inference and metrics
│   ├── statistics.py                # mean/std and paired t-tests
│   ├── verify.py                    # hashes, weights and reference ranks
│   ├── runtime.py                   # relative input/checkpoint loading
│   ├── resid_gr/                    # backbone, data, beam search and matching
│   ├── config.json                  # shared RL parameters
│   ├── requirements.txt
│   ├── data/                        # SID index, train.csv,valid.csv,test.csv
│   ├── checkpoints/
│   │   ├── index.json               # seed,method,step and hash for each model
│   │   ├── base/gr.pt               # supervised initialization
│   │   └── seed42/…seed46/          # grpo.pt,gspo.pt,sgpo.pt per seed
│   ├── references/
│   │   ├── results.md               # per-seed metrics and mean/std/t/p
│   │   ├── expected_metrics.json    # numerical reference
│   │   └── *-ranks.npz              # saved per-request ranks
│   └── tests/                       # policy-objective checks
└── office/                          # same structure, own data and weights
```

## Evaluate or train a dataset

```bash
cd industrial  # use office for Office_Products
python -m pip install -r requirements.txt
python verify.py
python evaluate.py --all --split valid --output runs/evaluation
python statistics.py --evaluated runs/evaluation/metrics.json --output runs/statistics
python train.py --method sgpo --seed 42 --output runs/sgpo-seed42
```

The shipped final models are `checkpoints/seed{42..46}/{grpo,gspo,sgpo}.pt`. Fresh training saves checkpoints to `--output`: e.g. `runs/sgpo-seed42/sgpo-step600.pt`. `run_all.py --output runs/training` creates `runs/training/seed42-grpo/`, `seed42-gspo/`, `seed42-sgpo/`,and corresponding seed43–46directories. Each run saves every100-step checkpoint and a separate validation-selected `best` checkpoint.

The main comparison uses all VALID requests and the actual600-step checkpoint, reporting overall HR/NDCG/MRR@5/10/20. Statistics use five paired RL seeds, sample standard deviation and two-sided paired t-tests withdf4. Full exact/partial and group metrics are also generated by the evaluator.
